Проблема ясна: `kubectl` с пользовательскими kubeconfig пытается подключиться к `localhost:8080`, потому что в этих файлах нет корректного `server` адреса. Нужно обновить все kubeconfig с правильным API URL.

## Решение: Обновить все kubeconfig файлы

```bash
# Получить правильный API URL из Minikube
# (Minikube слушает на 127.0.0.1 через проброшенный порт)
API_URL="https://127.0.0.1:$(docker port minikube 8443 | cut -d: -f2)"
echo "API URL: $API_URL"

# Или альтернативный способ
API_URL=$(minikube status --format='{{.APIServerURL}}' 2>/dev/null | head -1)
echo "API URL: $API_URL"
```

Если команды выше не работают, используйте ручной способ:

```bash
# Найти порт, который слушает minikube
docker port minikube 8443
# Вывод должен быть: 127.0.0.1:56024

# Вручную установите API_URL
API_URL="https://127.0.0.1:56024"
echo $API_URL
```

### Обновить все kubeconfig

```bash
# Получить правильный API URL
API_URL="https://127.0.0.1:56024"

# Получить CA сертификат
CA_CRT="$HOME/.minikube/ca.crt"

# Обновить все kubeconfig
for KCFILE in ./kubeconfigs/*.kubeconfig; do
    echo "Обновление: $KCFILE"
    kubectl config set-cluster propdevelopment \
        --certificate-authority="$CA_CRT" \
        --embed-certs=true \
        --server="$API_URL" \
        --kubeconfig="$KCFILE"
done

# Проверить
kubectl --kubeconfig=./kubeconfigs/auditor-ivanov.kubeconfig get pods --all-namespaces
```

При ошибке `HCS_E_HYPERV_NOT_INSTALLED` действительно необходимо включить два ключевых компонента: **Платформа виртуальной машины** и **Виртуализацию в BIOS/UEFI**.

### Шаг 1. Включение необходимых компонентов Windows (административная консоль)

Откройте **PowerShell** или **Командную строку** от имени **Администратора** и выполните эту команду:

```powershell
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

После её завершения введите вторую команду для установки ядра WSL2:

```powershell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
```

### Шаг 2. Включение виртуализации в BIOS/UEFI (наиболее частый источник ошибок)

Ваш процессор поддерживает виртуализацию, но она отключена на аппаратном уровне. Вам нужно зайти в BIOS/UEFI при загрузке компьютера (обычно клавиши **Del, F2, F10, F12**).

Названия опций могут отличаться. Ищите и **включите** (Set = Enabled):
*   **Intel**: `Intel Virtualization Technology` (VT-x), `Intel VT-d`
*   **AMD**: `SVM Mode` (Secure Virtual Machine), `AMD-V`

Также крайне желательно включить **`Hyper-V`** (в некоторых BIOS скрыт в расширенных настройках CPU).

### Шаг 3. Перезагрузка

После сохранения настроек BIOS (`F10`) компьютер перезагрузится. **Эти изменения обязательны.**

### Шаг 4. Установка WSL2 по рекомендации системы

После перезагрузки, следуя совету из ошибки, выполните в PowerShell (администратор):

```bash
wsl.exe --install --no-distribution
```

Эта команда завершит настройку WSL2. После неё перезагрузите ПК ещё раз.

### Шаг 5. Проверка и окончательная установка Ubuntu

1.  Проверьте, что WSL2 используется по умолчанию:
    ```bash
    wsl --set-default-version 2
    ```

2.  Теперь попробуйте установить ваш дистрибутив:
    ```bash
    wsl -d Ubuntu
    ```
    Если Ubuntu не установлена, сначала скачайте её: `wsl --install -d Ubuntu`

### Если ничего не помогло (крайние меры)

1.  **Антивирус**: Некоторые антивирусы (например, Kaspersky, McAfee) блокируют Hyper-V. Временно отключите их или добавьте исключения.
2.  **Версия Windows**: Введите `winver` в поиске. WSL2 требует **Windows 10 версии 2004** (сборка 19041 и выше) или Windows 11. Если версия старая, обновите Windows.
3.  **Групповые политики**: Если компьютер корпоративный, администратор мог отключить виртуализацию через групповые политики. Это лучше уточнить у вашего IT-отдела.

Попробуйте пройти по шагам, начиная с проверки BIOS. Это решит проблему в 95% случаев. Если ошибка останется, сообщите модель вашего процессора (Intel/AMD) и версию Windows (команда `winver`).
